Cambios v2
· Se agrega etiqueta BMC (section-lbl) entre la card ESXi y la card BMC de cada host.
· El chip de tipo (iDRAC / iLO / xClarity) se movió junto a la IP en la misma fila — ya no va junto al nombre.
· Cuando el estado es "Todo OK" la card tiene borde verde (--ok-bd) y el punto indicador cambia a verde (--ok). El select también se colorea verde como antes.
· El chip normaliza el raw string de InfraDoc: "iDRAC Management" → "iDRAC", "iLO Port" → "iLO", etc.
