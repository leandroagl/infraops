# Perfil de usuario

Accesible desde el menú de usuario en la toolbar (esquina superior derecha). Ruta: `/profile`.

## Datos personales

Muestra el email, nombre y rol asignado al usuario actual. El email no se puede modificar.

## Avatar

Para cambiar la foto de perfil:

1. Hacer clic en la imagen (o en el área de avatar si no hay imagen)
2. Seleccionar un archivo JPG, PNG o WEBP
3. El archivo no puede superar los **2 MB**
4. La imagen se sube automáticamente y se actualiza en la toolbar

El avatar se muestra en la esquina superior derecha de la aplicación en todas las vistas.

## Cambio de contraseña

Disponible en la misma pantalla. Se requiere ingresar la contraseña actual y la nueva dos veces para confirmar.

> Al recibir el acceso por primera vez, el sistema obliga a cambiar la contraseña temporal antes de poder usar la aplicación.
